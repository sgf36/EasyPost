Easy-Post Desktop - Microsoft Store listing update (v1.1.1)
Partner Center product 9NDSDL5LV5B5

WHAT THIS IS
A Partner Center "Import listings" folder that updates the Store listing across
all 47 languages:
  - "What's new" (Release notes) rewritten for version 1.1.1 and translated into
    every language.
  - Fresh screenshots of all nine pages, reflecting the current interface. Seven
    languages (en, zh-Hans, hi, es, fr, de, ja) have their own captured set; the
    other 40 reuse the English images, as before.
Everything else in the listing (title, description, features) is unchanged and
passed through untouched.

HOW TO IMPORT
1. Unzip this file.
2. In Partner Center, open the Easy-Post Desktop submission and choose
   "Import listings".
3. Select the FOLDER named "EasyPost-Store-Listings-IMPORT-v2" (the directory
   itself - not this zip, and not the .csv inside it).
4. The import is all-or-nothing: nothing is saved unless the whole file is clean,
   so a failure leaves the current listing exactly as it was.

IF IT STALLS
A single 47-language folder import can sit on "Importing" for a long time,
because Partner Center mints a separate asset per language. If that happens, the
same result is reachable in two faster passes (stage 1 = the seven localized
languages as a folder; stage 2 = a bare CSV that fans the English image URLs
across the other 40). Ask and I will generate the staged pair.

NOTE
This updates listing metadata and screenshots only. Submitting the actual 1.1.1
app package (MSIX) is a separate step.
