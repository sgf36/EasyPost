اسٹور میں دیکھیں

Windows ایک نیلا انتباہ دکھاتا ہے۔ یہ متوقع ہے۔

“Windows protected your PC” پہلی بار ڈاؤن لوڈ چلانے پر ظاہر ہوتا ہے، کیونکہ یہ بلڈ ابھی تک کوڈ سائن شدہ نہیں ہے۔ More info پر کلک کریں، پھر Run anyway پر۔

یہ اس بات کی علامت نہیں کہ کچھ غلط ہے — SmartScreen یہ پیغام کسی بھی ایسی ایپلیکیشن کے لیے دکھاتا ہے جس کے پبلشر کو وہ ابھی تک نہیں پہچانتا، اور ایک سرٹیفکیٹ کا انتظام کیا جا رہا ہے۔ اگر آپ فائل چلانے سے پہلے خود اس کی تصدیق کرنا چاہیں تو اس کا چیک سم نیچے دی گئی فہرست سے موازنہ کریں:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Microsoft Store بلڈ مائیکروسافٹ کی جانب سے دستخط شدہ ہے اور ایسا کوئی انتباہ نہیں دکھاتا، اس لیے ایک بار جب آپ کے پاس اسٹور لائسنس ہو تو Windows پر یہ زیادہ آسان راستہ ہے۔

شروع کرنا

  1. ایپلیکیشن انسٹال اور کھولیں۔
  2. ایکٹیویشن اسکرین پر اپنی لائسنس کلید پیسٹ کریں۔ یہ خریداری کے وقت ای میل کے ذریعے موصول ہوئی تھی — “Easy-Post Desktop licence key” تلاش کریں۔ اسٹور انسٹالز میں یہ مرحلہ درکار نہیں۔
  3. اپنی EasyPost API کلید پیسٹ کریں۔ Easy-Post Desktop خود کوئی پوسٹیج فروخت نہیں کرتا؛ یہ آپ کے اپنے EasyPost اکاؤنٹ کو چلاتا ہے۔ easypost.com پر مفت سائن اپ کریں۔ ٹیسٹ موڈ کی کلید کی مدد سے آپ اصل لیبل خریدے بغیر ہر چیز آزما سکتے ہیں۔

بعد میں کمپیوٹر تبدیل کرنا متوقع ہے اور مستقل طور پر آپ کو کچھ خرچ نہیں کرتا — ایپلیکیشن کے اندر، سیٹنگز میں جا کر پرانی مشین کو رہا کریں۔
