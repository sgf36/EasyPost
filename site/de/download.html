Der Windows-Download ist codesigniert

Ab Version 1.2.7 tragen beide ausführbaren Dateien eine von Microsoft ausgestellte Public-Trust-Signatur auf den Namen Spencer Fields, sodass Windows den Herausgeber nennt, anstatt vor einem unbekannten zu warnen. Klicken Sie mit der rechten Maustaste auf die Datei und wählen Sie Eigenschaften, dann Digitale Signaturen, um sie einzusehen.

Eine Signatur ist neu in dieser Version, und SmartScreen baut seine Reputation danach auf, wie oft eine signierte Anwendung heruntergeladen und ausgeführt wird. Auf einem Rechner mit aktiviertem Smart App Control kann ein so junges Zertifikat trotzdem zurückgehalten werden. Sollte das geschehen, ist die Version aus dem Microsoft Store der reibungslosere Weg, da sie Microsofts eigene Signatur trägt.

Um den Download selbst vor der Ausführung zu prüfen, vergleichen Sie seine Prüfsumme mit der folgenden Liste:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Erste Schritte

  1. Installieren und öffnen Sie die Anwendung.
  2. Fügen Sie Ihren Lizenzschlüssel auf dem Aktivierungsbildschirm ein. Er wurde Ihnen beim Kauf per E-Mail zugeschickt – suchen Sie nach „Easy-Post Desktop licence key“. Bei Store-Installationen entfällt dieser Schritt.
  3. Fügen Sie Ihren EasyPost-API-Schlüssel ein. Easy-Post Desktop verkauft selbst kein Porto; es steuert Ihr eigenes EasyPost-Konto. Registrieren Sie sich kostenlos unter easypost.com. Mit einem Test-Schlüssel können Sie alles ausprobieren, ohne echte Labels zu kaufen.

Ein späterer Computerwechsel ist vorgesehen und verursacht keine dauerhaften Kosten – geben Sie den alten Computer einfach in der Anwendung unter Einstellungen frei.

Voraussetzungen

  • Windows 10 Version 1809 oder neuer, 64-Bit – oder macOS auf Apple Silicon
  • Ein EasyPost-Konto und ein API-Schlüssel
  • Eine Internetverbindung, um Labels zu kaufen und einmalig zu aktivieren
