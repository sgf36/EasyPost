“Windows 已保护您的电脑”会在您首次运行下载文件时出现，因为此版本尚未进行代码签名。请点击更多信息，然后点击仍要运行。

这并不代表出现了任何问题——SmartScreen 会对任何它尚未识别发布者的应用程序显示此提示,相关证书正在申请中。如果您希望在运行前自行验证文件,可将其校验和与下方列表进行比对:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Microsoft Store 版本由 Microsoft 签名，不会显示此类警告，因此一旦您拥有商店许可证，这便是在 Windows 上更顺畅的方式。

开始使用

  1. 安装并打开应用程序。
  2. 在激活界面粘贴您的许可证密钥。该密钥在您购买时已通过电子邮件发送给您——请搜索“Easy-Post Desktop licence key”。通过商店安装则无需此步骤。
  3. 粘贴您的 EasyPost API 密钥。Easy-Post Desktop 本身不出售邮资，它只是驱动您自己的 EasyPost 账户。请前往 easypost.com 免费注册。测试模式密钥可让您在不购买真实标签的情况下尝试所有功能。

日后更换电脑是正常情况,并不会产生任何永久性费用——只需在应用程序的“设置”中释放旧设备即可。
