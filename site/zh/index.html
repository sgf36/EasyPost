它的作用是什么

一整套运输控制台，而不只是一个运费小工具。

比价

获取您 EasyPost 账户下所有承运商的实时运费，按最低价优先排序，并标出最快的选项。只需两个邮政编码，就能在保存地址之前先查看某条线路的价格。

打印机认可的标签

选择 PNG、PDF、ZPL 或 EPL 格式，以及精确尺寸——4x6、4x7、4x8、4x5 或 8.5x11——让标签无论打印在热敏纸还是普通纸上都恰到好处。购买后的标签会在应用内直接显示。

国际运输与海关

引导式海关申报，可逐项列明内容物，并内置协调关税表查询功能，直接比对美国国际贸易委员会数据库。

追踪从不掉队

每五分钟轮询一次为标准做法，也可选择通过本地隧道接收实时 webhook 推送更新，以获得即时状态变化。

批量发货

导入收件人 CSV 文件,在扣费前先进行校验,再批量计费、批量购买并生成合并标签。

标签之后

未使用标签的退款、附加保险、快递员上门取件，以及包裹丢失或损坏的保险理赔——全部可在同一窗口完成。

您的数据仍归您所有

地址簿、发货记录和报表都保存在您本机的本地数据库中。除发送给 EasyPost 之外，不会发送到任何其他地方。

支持 50 种语言

完整界面已翻译为五十种语言，可在设置中选择。

开始使用

您需要拥有自己的 EasyPost 账户——注册是免费的。

独立客户端

Easy-Post Desktop 是 EasyPost 的独立桌面客户端，与 EasyPost 或任何快递公司均无关联，未获其认可，也非其分销商。

您的账户，您的费率

您需提供自己的 EasyPost API 密钥,邮资将按您自己的费率通过您的 EasyPost 账户购买。快递公司名称仅用于标识所报的服务,所有快递公司商标均归其各自所有者所有。

系统要求

Windows 10 版本 1809 或更高版本（64 位），或搭载 Apple 芯片的 macOS 12 Monterey 或更高版本。不支持 Intel Mac。需要网络连接才能访问 EasyPost。
