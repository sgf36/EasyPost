隐私政策

最后更新：2026 年 7 月 21 日

本政策说明 Easy-Post Desktop 存储哪些数据、传输哪些数据以及传输给谁。数据控制者为 Spencer Fields，一名在英国注册的个体经营者，联系方式为 Apps@spencerfields.com。

简要说明

运单数据保存在您自己的计算机上。该应用程序不含任何分析工具、遥测功能、广告标识符或崩溃报告。供应商只会从应用程序收到一件事，且仅收到一次：记录某台计算机正在使用您许可证所涵盖的一个席位，具体内容详见下文。您运送什么、如何使用该应用程序，这些信息永远不会被传输。

应用程序在您计算机上存储的内容

  • 您的 EasyPost API 密钥，保存在操作系统的凭据存储中——Windows 凭据管理器或 macOS 钥匙串——且绝不会以纯文本文件形式写入。
  • 一个本地数据库，其中包含地址簿、运单与追踪记录、批次记录、索赔、取件安排以及关税代码缓存。这些数据存放在您计算机上标准的每用户应用数据目录中。
  • 本地偏好设置，例如所选语言和标签尺寸，以及已激活的许可证密钥（如有）。

以上内容均不会被应用程序同步、备份或上传到任何地方。删除应用程序及其数据目录会将其全部清除。

应用程序发送的内容及发送对象

  • EasyPost。 为执行所请求的操作，地址、包裹、报关、追踪、保险、取件及索赔数据会通过您自己的 EasyPost 账户发送至 EasyPost 的 API。EasyPost 是该数据的独立数据控制者，受其自身隐私政策约束。
  • 美国国际贸易委员会。 使用关税代码查询功能时，仅搜索词会发送至该委员会的公共数据库，不会附带任何运单或个人数据。
  • 承运商标签图像。 已购买的标签文件会从 EasyPost 提供的地址获取，以便显示和保存。
  • Cloudflare，仅在您启用实时追踪时使用。 该可选的 Webhook 功能默认关闭。开启后会启动一个本地接收器和一个 Cloudflare 隧道，以便 EasyPost 能够将追踪事件传送到您的计算机。您可以随时在“设置”中再次将其关闭。
  • 许可证激活服务。 仅适用于直接下载版本，且仅在激活或释放某台计算机时使用。发送的具体内容见下一节。Microsoft Store 版本从不会与该服务通信。

许可证激活

每个许可证覆盖一定数量的计算机，因此需要有某种方式对其进行计数。激活操作会记录本台计算机正在使用其中一个坐席。此过程仅发生一次：该服务会返回一份经签名的确认信息，该信息存储在您的计算机上，此后无需任何网络连接即可进行核验。不存在周期性签到、心跳信号或使用情况报告。

发送的内容。 一个单向的计算机指纹，由机器标识符与您的许可证密钥组合生成；该标识符本身永远不会离开您的计算机，且该指纹无法被反向推导出原始标识符。由于您的许可证密钥参与了该计算过程，同一台计算机在不同许可证下会生成互不相关的值，因此无法在客户之间关联激活记录。随附发送的还有：从主机名获取的计算机名称，以便您在释放某台计算机时能够区分自己的机器；包含在您许可证密钥中的订单参考号；以及日期。

绝不会发送的内容。 您的 EasyPost API 密钥、您的地址、您的运单、您的追踪或报关数据、您打开的任何文件，或有关您如何使用该应用程序的任何信息。

保存时长。 只要许可证仍在使用中，记录就会保留。释放某台计算机会立即删除其记录。六个月内未激活的计算机记录会被自动删除。购买款项退款会删除该许可证的所有记录。

若服务不可用。 应用程序会继续正常工作。它会给自己一段有限的宽限期，并稍后重试。我方服务的中断绝不应影响您已付费软件的正常运行。

购买许可证

购买事务由Paddle.com Market Ltd处理，该公司是我们授权的经销商及记录商户。付款信息完全由 Paddle 收集和处理。供应商永远不会看到、接收或存储卡号或银行信息。

Paddle 会将购买者的电子邮件地址和订单编号提供给供应商，用于生成并发送许可证密钥。Paddle 对个人数据的处理受其自身的隐私声明约束。

许可证密钥邮件通过Resend（一家电子邮件发送服务商）发送，该服务商仅出于此目的处理收件人地址。

购买者的电子邮件地址和订单编号会在支持许可证及满足会计义务所需的期间内予以保留。这些信息绝不会被出售、出租或用于营销。

本网站

本网站页面在您选择允许之前不会设置任何 Cookie，也没有访客账户。

数据分析。本网站使用两项数据分析服务，且在您首次访问时未做出选择前，任何与分析相关的内容都不会加载。若您选择拒绝，则不会设置任何分析类 Cookie，也不会向任何一方发送数据。您可以随时改变主意，只需清除浏览器中本网站的数据，该选择就会重新出现。

Google Analytics 会汇总报告本网站的使用情况。若您选择接受，它会设置自己的 Cookie，并接收使用数据，其中包括经过缩短处理的 IP 地址。Google 作为独立的处理方，其数据处理受其自身的隐私政策约束。

Microsoft Clarity 显示用户阅读页面的哪些部分以及在何处遇到困难。它不仅进行汇总统计，还会记录访问期间页面的滚动和点击方式，并回放这些交互过程，同时设置自己的 Cookie 以区分不同的访问。任何在表单字段中输入或从下拉菜单中选择的内容，在离开您的浏览器之前都会被遮蔽：Clarity 在其提供的每种模式下都会遮蔽这些内容，且没有关闭此功能的方式。在此处所使用的设置下，页面上任何位置出现的数字和电子邮件地址也会被遮蔽。Microsoft 作为独立的处理方，其数据处理受Microsoft 隐私声明约束。由于访问记录并非汇总信息，因此不能在未经询问的情况下运行——这正是为何提供选择而非默认启用的原因。

字体与日志。网页字体从 Google Fonts 加载，作为提供字体文件的正常结果，Google Fonts 会接收请求方的 IP 地址。托管服务商会出于安全和诊断目的保留标准的服务器访问日志。

往来通信

为处理支持或退款事宜而进行的电子邮件或电话联系，仅在处理该事项及留存记录所需的期间内予以保留。

支持部分的联系表单会收集您输入的姓名、电子邮件地址、所选主题和留言内容，以及提交所来自的 IP 地址。留言会直接以电子邮件方式发送至支持邮箱，不会存储在任何数据库中。IP 地址会记录在邮件中，并短暂保存在一个临时的速率限制文件中，其唯一目的是防止该表单被滥用于发送大量邮件；它不会被用于识别或分析任何人。此过程不涉及任何表单分析服务、追踪像素或第三方表单提供商——该表单完全由本服务器处理。

您的权利

根据《英国通用数据保护条例》及相关法律，您可以要求查阅我们所持有的关于您的个人数据，要求更正或删除该数据，反对对其进行处理，或要求获得一份可携带格式的副本。请写信至Apps@spencerfields.com，我们将在一个月内回复您的请求。

与购买相关所持有的数据仅限于电子邮件地址、订单编号和许可证密钥。供应商完全不持有配送数据，因此有关配送数据的请求应直接向 EasyPost 提出。

您可以向英国信息专员办公室（Information Commissioner's Office）投诉，网址为ico.org.uk。
