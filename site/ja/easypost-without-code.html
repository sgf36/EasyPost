APIなし・ダッシュボードなし・自分自身のアカウント

コードを書かずにEasyPostを利用

EasyPostは開発者向けに作られていますが、利用するために開発者である必要はありません。Easy-Post Desktopを使えば、通常のデスクトップアプリから、お客様自身のEasyPostアカウントでラベルを印刷し、配送業者の料金を比較し、荷物を追跡できます。コードを書く必要も、ウェブダッシュボードに張り付く必要もありません。

Microsoft Storeで無料で試す FAQを読む

問題:EasyPostはコードを書けることを前提としています

EasyPostのマルチキャリア料金比較とラベルは非常に優れていますが、利用するための入口は開発者向けAPIとウェブダッシュボードの2つしかありません。ラベルを1枚買いたいだけの場合や、チームが一日中発送作業を行っている場合、APIに対してコードを書くのは現実的ではなく、ダッシュボードも大量処理向けには作られていません。まさにこの理由から、多くのEasyPostアカウントが十分に活用されずに放置されています。

解決策:自分自身のアカウントで使えるデスクトップアプリ

Easy-Post Desktopはお客様自身のEasyPost APIキーに接続し、それをクリック操作だけで使えるアプリケーションに変えます。

  • 住所を入力し、荷物の種類を選ぶだけで、アカウント内のすべての配送業者から料金を取得し、安い順に表示します。
  • わずか数クリックでラベルを購入して印刷 — PNG、PDF、ZPLまたはEPL形式で、お使いのプリンターに合わせたサイズで出力できます。
  • 荷物を追跡し、住所を確認し、通関情報を取得し、HTS関税番号を調べられます。
  • 注文データのCSVファイルをまとめて一括発送:インポート、検証、料金取得、購入まで対応。
  • 返金、保険、集荷依頼、保険金請求まで — ターミナルもダッシュボードも一度も開くことなく行えます。

郵送料はEasyPostが直接請求するため、このアプリがお客様の資金を扱ったり、上乗せ料金を加えたりすることはありません。

EasyPost APIキーはどこで取得できますか?

easypost.comで無料登録し、アカウントのAPI Keysページからご自身のAPIキーをコピーしてください。それをEasy-Post Desktopの初回起動時に貼り付けます。テストモードのキーを使えば、実際の配送業者への請求なしにすべての機能をお試しいただけます。アプリはテストモードでは無料で、準備が整ったら1回限り$29.99のアンロックで本番(実際の)ラベルが利用可能になります。

AIアシスタントに任せたい方は?

本アプリはModel Context Protocol (MCP)にも対応しているため、Claude、Cursor、VS CodeなどのAIエージェントを配送データに接続し、料金の比較や質問への回答を行わせることができます。実際の購入はアプリ内での人による承認ステップを必ず経るため、お客様の同意なしに何かが購入されることはありません。

Easy-Post Desktopを入手 Easy-Post Desktopとは?

Easy-Post Desktopは、英国で設立された個人事業主Spencer Fieldsの製品です。 これは独立した非公式のクライアントであり、EasyPostと提携、承認、後援を受けているものではありません。 EasyPostのアカウントとAPIキーが必要です。
