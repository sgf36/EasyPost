Windowsに青い警告が表示されます。これは想定どおりです。

「Windowsによって PC が保護されました」は、このビルドがまだコード署名されていないため、ダウンロードしたファイルを初めて実行したときに表示されます。詳細情報をクリックし、続けて実行をクリックしてください。

これは何か問題があることを示すものではありません。SmartScreenは、発行者をまだ認識していないすべてのアプリケーションに対してこの警告を表示するもので、現在証明書の取得を進めています。実行する前にファイルを自分で確認したい場合は、以下のリストのチェックサムと比較してください。

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Microsoft Storeビルドは Microsoft によって署名されているため、このような警告は表示されません。Storeのライセンスをお持ちであれば、Windowsではこちらの方がスムーズな方法です。

はじめに

  1. アプリケーションをインストールして開いてください。
  2. アクティベーション画面でライセンスキーを貼り付けてください。購入時にメールで届いています。「Easy-Post Desktop licence key」で検索してください。Storeからインストールした場合、この手順は不要です。
  3. EasyPost APIキーを貼り付けてください。Easy-Post Desktopは独自に郵送料を販売するものではなく、お客様ご自身のEasyPostアカウントを利用します。easypost.comで無料登録できます。テストモードのキーを使えば、実際のラベルを購入せずにすべての機能を試せます。

後でコンピューターを変更することは想定されており、永続的な追加費用はかかりません。アプリケーション内の設定から、古いコンピューターの登録を解除してください。

必要条件

  • Windows 10 バージョン 1809 以降(64ビット)、または Apple silicon 搭載の macOS
  • EasyPost のアカウントと API キー
  • ラベルを購入し、一度だけ有効化するためのインターネット接続
