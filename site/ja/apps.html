アプリ

Easy-Post のアプリ

Mac と Windows 向けのデスクトップアプリ、そして iPhone 向けのコンパニオンアプリ。このページのものはすべてアプリストアから提供され、自動で最新の状態に保たれます。

Easy-Post Desktop

作業を行うその端末で、出荷を作成し、配送業者の料金をリアルタイムで比較し、ラベルを印刷できます。ストア版は自動で更新され、ライセンスキーは不要です。

Mac App Storeでダウンロード Microsoft Storeで入手

ストアを介したくない方のために、Windows と macOS は直接ダウンロードでも提供しています。こちらのビルドには有償のライセンスキーが必要です。

Easy-Post Mobile Companion

デスクトップアプリと一度ペアリングするだけで、スマートフォンで配送状況を確認できます。インストールは無料で、ペアリングには有償の Easy-Post Desktop 製品版ライセンスが必要です。

App Storeでダウンロード

Android 版は Google Play での公開に向けてテスト中です。モバイルアプリについて詳しく。
