Aplikasi

Aplikasi Easy-Post

Aplikasi desktop untuk Mac dan Windows, serta aplikasi pendamping seluler untuk iPhone. Semua yang ada di halaman ini berasal dari toko aplikasi, sehingga selalu diperbarui secara otomatis.

Easy-Post Desktop

Buat pengiriman, bandingkan tarif kurir langsung, dan cetak label, di komputer tempat pekerjaan itu dilakukan. Edisi toko memperbarui dirinya sendiri dan tidak memerlukan kunci lisensi.

Windows dan macOS juga ditawarkan sebagai unduhan langsung, bagi siapa pun yang lebih memilih untuk tidak melalui toko. Versi tersebut memerlukan kunci lisensi berbayar.

Easy-Post Mobile Companion

Pelacakan pengiriman di ponsel, dipasangkan sekali dengan aplikasi desktop. Gratis untuk dipasang, dan diperlukan lisensi produksi Easy-Post Desktop berbayar untuk melakukan pemasangan.

Edisi Android masih dalam pengujian menjelang peluncuran di Google Play. Selengkapnya tentang aplikasi seluler.
