Aplikasi

Aplikasi Easy-Post

Aplikasi desktop untuk Mac dan Windows, serta aplikasi pendamping untuk iPhone. Semua yang ada di halaman ini berasal dari toko aplikasi, sehingga selalu tetap mutakhir dengan sendirinya.

Easy-Post Desktop

Buat pengiriman, bandingkan tarif kurir secara langsung, dan cetak label, di komputer tempat pekerjaan berlangsung. Edisi toko memperbarui dirinya sendiri dan tidak memerlukan kunci lisensi.

Unduh di Mac App Store Dapatkan dari Microsoft Store

Windows dan macOS juga ditawarkan sebagai unduhan langsung bagi siapa pun yang tidak ingin melalui toko. Versi tersebut memerlukan kunci lisensi berbayar.

Easy-Post Mobile Companion

Pelacakan pengiriman di ponsel, cukup disandingkan sekali dengan aplikasi desktop. Gratis dipasang, dan lisensi produksi Easy-Post Desktop berbayar diperlukan untuk menyandingkan perangkat.

Unduh di App Store

Edisi Android sedang diuji menjelang rilis di Google Play. Selengkapnya tentang aplikasi seluler.
