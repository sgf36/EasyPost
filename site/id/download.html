Unduhan Windows ditandatangani secara kode

Mulai versi 1.2.7, kedua executable membawa tanda tangan Public Trust yang diterbitkan oleh Microsoft atas nama Spencer Fields, sehingga Windows menampilkan nama penerbitnya, bukan memperingatkan tentang penerbit yang tidak dikenalinya. Klik kanan pada berkas, pilih Properties, lalu Digital Signatures untuk melihatnya.

Tanda tangan ini muncul pertama kali di versi 1.2.7, dan SmartScreen membangun reputasinya berdasarkan seberapa sering suatu aplikasi bertanda tangan diunduh dan dijalankan. Pada komputer dengan Smart App Control diaktifkan, sertifikat sebaru ini mungkin masih ditahan. Jika hal itu terjadi, versi Microsoft Store memiliki tanda tangan Microsoft sendiri dan merupakan jalan yang lebih lancar.

Untuk memeriksa sendiri unduhan tersebut sebelum menjalankannya, bandingkan checksum-nya dengan daftar di bawah ini:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Memulai

  1. Instal dan buka aplikasi.
  2. Tempelkan kunci lisensi Anda pada layar aktivasi. Kunci ini dikirim melalui email saat Anda membeli — cari “Easy-Post Desktop licence key”. Instalasi dari Store tidak memerlukan langkah ini.
  3. Tempelkan kunci API EasyPost Anda. Easy-Post Desktop tidak menjual ongkos kirim sendiri; aplikasi ini menjalankan akun EasyPost Anda sendiri. Daftar gratis di easypost.com. Kunci mode uji memungkinkan Anda mencoba semuanya tanpa membeli label sungguhan.

Mengganti komputer di kemudian hari adalah hal yang wajar dan tidak dikenai biaya permanen — lepaskan mesin lama dari dalam aplikasi, pada bagian Pengaturan.

Versi lama dan sumber

Setiap rilis, beserta catatan dan checksum-nya, dicantumkan di GitHub. Aplikasi ini bersifat sumber terbuka di bawah lisensi MIT; sumbernya ada di github.com/sgf36/EasyPost.
