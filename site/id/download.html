Lihat di Store

Windows menampilkan peringatan biru. Ini memang sudah diperkirakan.

“Windows melindungi PC Anda” muncul saat pertama kali Anda menjalankan unduhan, karena build ini belum ditandatangani secara kode. Klik Info lainnya, lalu Jalankan saja.

Ini bukan tanda bahwa ada yang salah — SmartScreen menampilkannya untuk aplikasi apa pun yang penerbitnya belum dikenali, dan sertifikat sedang diurus. Jika Anda lebih suka memverifikasi file sendiri sebelum menjalankannya, bandingkan checksum-nya dengan daftar di bawah ini:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Build Microsoft Store ditandatangani oleh Microsoft dan tidak menampilkan peringatan semacam itu, sehingga menjadi cara yang lebih lancar di Windows setelah Anda memiliki lisensi Store.

Memulai

  1. Instal dan buka aplikasi.
  2. Tempelkan kunci lisensi Anda pada layar aktivasi. Kunci ini dikirim melalui email saat Anda membeli — cari “Easy-Post Desktop licence key”. Instalasi dari Store tidak memerlukan langkah ini.
  3. Tempelkan kunci API EasyPost Anda. Easy-Post Desktop tidak menjual ongkos kirim sendiri; aplikasi ini menjalankan akun EasyPost Anda sendiri. Daftar gratis di easypost.com. Kunci mode uji memungkinkan Anda mencoba semuanya tanpa membeli label sungguhan.

Mengganti komputer di kemudian hari adalah hal yang wajar dan tidak dikenai biaya permanen — lepaskan mesin lama dari dalam aplikasi, pada bagian Pengaturan.
