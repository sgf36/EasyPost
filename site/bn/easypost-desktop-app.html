EasyPost-এর জন্য একটি ডেস্কটপ অ্যাপ

EasyPost একটি শিপিং API। Easy-Post Desktop হল এর উপরে থাকা নেটিভ ডেস্কটপ অ্যাপ — যার মাধ্যমে আপনি কোনো কোড না লিখে বা ব্রাউজার ড্যাশবোর্ডে সময় না কাটিয়েই আপনার নিজের EasyPost অ্যাকাউন্টে রেট তুলনা করতে, লেবেল কিনতে ও প্রিন্ট করতে এবং পার্সেল ট্র্যাক করতে পারবেন।

Microsoft Store-এ বিনামূল্যে চেষ্টা করুন মূল্য দেখুন

EasyPost-এর জন্য একটি ডেস্কটপ অ্যাপ কেন?

EasyPost আপনাকে দুর্দান্ত মাল্টি-ক্যারিয়ার শিপিং সুবিধা দেয়, কিন্তু সরাসরি ব্যবহারের জন্য আপনাকে হয় API-এর বিরুদ্ধে কোড লিখতে হয়, নয়তো ওয়েব ড্যাশবোর্ডে কাজ করতে হয়। আপনি যদি একজন মার্চেন্ট, অপারেশনস কর্মী বা ওয়্যারহাউস দলের সদস্য হন, তবে দিনভর লেবেল প্রিন্ট করার জন্য এর কোনোটিই কাম্য নয়। Easy-Post Desktop একটি প্রকৃত নেটিভ অ্যাপ্লিকেশন (Windows এবং macOS) যা আপনার নিজের EasyPost অ্যাকাউন্ট এবং API কী-এর সাথে সংযুক্ত হয় এবং একটি দ্রুত, কেন্দ্রীভূত ইন্টারফেসে সম্পূর্ণ কর্মপ্রবাহ প্রদান করে।

এটি একটি ফ্রন্ট-এন্ড, রিসেলার নয়: পোস্টেজের বিল সরাসরি EasyPost থেকে করা হয়, এবং অ্যাপটি কখনো কোনো কিছুর দাম বাড়ায় না বা আপনার টাকা স্পর্শ করে না।

অ্যাপটি যা করে

  • রেট তুলনা — USPS, FedEx, UPS এবং আপনার অ্যাকাউন্টের প্রতিটি ক্যারিয়ারের লাইভ রেট তুলনা করুন, সবচেয়ে সস্তাটি প্রথমে দেখুন।
  • লেবেল — PNG, PDF, ZPL বা EPL ফরম্যাটে, আপনার প্রিন্টারের প্রয়োজনীয় সঠিক আকারে কিনুন এবং প্রিন্ট করুন।
  • ট্র্যাকিং — স্বয়ংক্রিয় পোলিং বা ঐচ্ছিক রিয়েল-টাইম পুশ আপডেটের মাধ্যমে পার্সেল পর্যবেক্ষণ করুন।
  • অ্যাড্রেস বুক ও যাচাইকরণ — ১৯৭টি দেশ কভার করে দেশ-সচেতন ফিল্ড।
  • কাস্টমস ও HTS লুকআপ — সম্পূর্ণ কাস্টমস ডেটা সংগ্রহ করুন এবং লাইভ U.S. ট্যারিফ কোড খুঁজুন।
  • রিফান্ড, ইন্স্যুরেন্স, পিকআপ, ক্লেইম এবং ব্যাচ CSV — সম্পূর্ণ শিপিং জীবনচক্র এক জায়গায়।
  • AI-এজেন্ট অ্যাক্সেস (MCP) — Claude বা Cursor-এর মতো একটি অ্যাসিস্ট্যান্টকে আপনার শিপিং ডেটার সাথে সংযুক্ত করে রেট তুলনা করুন, প্রতিটি ক্রয় অ্যাপে আপনার দ্বারা অনুমোদিত হবে।

চেষ্টা করা বিনামূল্যে, সৎ মূল্য নির্ধারণ

অ্যাপটি ইনস্টল করা বিনামূল্যে এবং সম্পূর্ণভাবে EasyPost-এর টেস্ট মোডে চলে, যাতে আপনি কোনো অর্থ প্রদানের আগে আপনার সম্পূর্ণ কর্মপ্রবাহ আপনার অ্যাকাউন্টের বিরুদ্ধে যাচাই করতে পারেন। একটি একবারের $29.99 আনলক আপনার কম্পিউটারে প্রোডাকশন লেবেল সক্রিয় করে — কোনো সাবস্ক্রিপশন নেই, কোনো টাইমার নেই। একাধিক কম্পিউটার প্রয়োজন এমন দলগুলি এই সাইটে প্রতি সিট লাইসেন্স নিতে পারে।

ব্যক্তিগত ও উন্মুক্ত

আপনার API কী Windows Credential Manager-এ সংরক্ষিত থাকে এবং শুধুমাত্র EasyPost-এর API-তে পাঠানো হয়। শিপিং ডেটা আপনার মেশিনেই থাকে — কোনো অ্যানালিটিক্স নেই, কোনো টেলিমেট্রি নেই। অ্যাপটি MIT লাইসেন্সের অধীনে ওপেন সোর্স, তাই এটি আপনার অ্যাকাউন্টের সাথে কীভাবে সংযুক্ত হয় তার কিছুই গোপন নেই।

Easy-Post Desktop সংগ্রহ করুন সোর্স দেখুন

Easy-Post Desktop হল Spencer Fields-এর একটি পণ্য, যিনি যুক্তরাজ্যে প্রতিষ্ঠিত একজন একক ব্যবসায়ী (sole trader)। এটি একটি স্বাধীন, অনানুষ্ঠানিক ক্লায়েন্ট এবং EasyPost-এর সাথে সংশ্লিষ্ট, অনুমোদিত বা পৃষ্ঠপোষকতাপ্রাপ্ত নয়। একটি EasyPost অ্যাকাউন্ট এবং API কী প্রয়োজন।
