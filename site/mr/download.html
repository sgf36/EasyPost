स्टोअरमध्ये पहा

Windows मध्ये निळा इशारा दिसतो. हे अपेक्षितच आहे.

“Windows protected your PC” हा संदेश डाउनलोड पहिल्यांदा चालवताना दिसतो, कारण हे बिल्ड अद्याप कोड-साइन केलेले नाही. More info वर क्लिक करा, नंतर Run anyway वर क्लिक करा.

यामध्ये काही चूक असल्याचे हे चिन्ह नाही — ज्या कोणत्याही अनुप्रयोगाचा प्रकाशक SmartScreen ला अद्याप ओळखता येत नाही, त्याच्यासाठी हा इशारा दाखवला जातो, आणि प्रमाणपत्राची व्यवस्था केली जात आहे. फाइल चालवण्यापूर्वी तुम्ही स्वतः ती पडताळून पाहू इच्छित असल्यास, तिचा चेकसम खालील यादीशी जुळवून पहा:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Microsoft Store बिल्ड हे Microsoft ने स्वाक्षरीकृत असते आणि त्यात असा कोणताही इशारा दाखवला जात नाही, त्यामुळे एकदा तुमच्याकडे Store परवाना असेल की Windows वर हा अधिक सुरळीत मार्ग ठरतो.

सुरुवात कशी करावी

  1. अनुप्रयोग इन्स्टॉल करा आणि उघडा.
  2. सक्रियकरण स्क्रीनवर तुमची लायसन्स की पेस्ट करा. खरेदी करताना ती ईमेलद्वारे आली होती — “Easy-Post Desktop licence key” शोधा. स्टोअरवरून केलेल्या इन्स्टॉलमध्ये ही पायरी वगळली जाते.
  3. तुमची EasyPost API की पेस्ट करा. Easy-Post Desktop स्वतः कोणतेही पोस्टेज विकत नाही; ते तुमच्याच EasyPost खात्याद्वारे चालते. easypost.com वर मोफत नोंदणी करा. टेस्ट-मोड की तुम्हाला खरे लेबल्स विकत न घेता सर्व काही आजमावून पाहू देते.

नंतर संगणक बदलणे स्वाभाविक आहे आणि त्यासाठी कायमस्वरूपी कोणताही खर्च येत नाही — अनुप्रयोगामध्ये, सेटिंग्जमध्ये जाऊन जुना संगणक मोकळा करा.
