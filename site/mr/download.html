स्टोअरमध्ये पहा

Windows डाउनलोड कोड-स्वाक्षरीयुक्त आहे

आवृत्ती 1.2.7 पासून पुढे, दोन्ही एक्झिक्युटेबल्समध्ये Spencer Fields या नावाने Microsoft-जारी केलेली Public Trust स्वाक्षरी आहे, त्यामुळे Windows अपरिचित प्रकाशकाबद्दल इशारा देण्याऐवजी प्रकाशकाचे नाव दाखवते. फाइलवर उजवे-क्लिक करा, Properties निवडा, नंतर Digital Signatures निवडून ती पाहा.

स्वाक्षरी 1.2.7 मध्ये आली, आणि SmartScreen स्वाक्षरी केलेले अ‍ॅप्लिकेशन किती वेळा डाउनलोड आणि चालवले जाते यावरून आपली प्रतिष्ठा तयार करते. Smart App Control सुरू असलेल्या यंत्रावर, इतकं अलीकडचं प्रमाणपत्र अजूनही रोखलं जाऊ शकतं. असं झाल्यास, Microsoft Store बिल्डवर Microsoft ची स्वतःची स्वाक्षरी असते आणि तो अधिक सुरळीत मार्ग ठरतो.

डाउनलोड रन करण्यापूर्वी ते स्वतः तपासण्यासाठी, त्याचा चेकसम खालील यादीशी जुळवून पाहा:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

सुरुवात कशी करावी

  1. अनुप्रयोग इन्स्टॉल करा आणि उघडा.
  2. सक्रियकरण स्क्रीनवर तुमची लायसन्स की पेस्ट करा. खरेदी करताना ती ईमेलद्वारे आली होती — “Easy-Post Desktop licence key” शोधा. स्टोअरवरून केलेल्या इन्स्टॉलमध्ये ही पायरी वगळली जाते.
  3. तुमची EasyPost API की पेस्ट करा. Easy-Post Desktop स्वतः कोणतेही पोस्टेज विकत नाही; ते तुमच्याच EasyPost खात्याद्वारे चालते. easypost.com वर मोफत नोंदणी करा. टेस्ट-मोड की तुम्हाला खरे लेबल्स विकत न घेता सर्व काही आजमावून पाहू देते.

नंतर संगणक बदलणे स्वाभाविक आहे आणि त्यासाठी कायमस्वरूपी कोणताही खर्च येत नाही — अनुप्रयोगामध्ये, सेटिंग्जमध्ये जाऊन जुना संगणक मोकळा करा.
