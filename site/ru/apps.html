Приложения

Приложения Easy-Post

Настольное приложение для Mac и Windows и мобильное приложение-спутник для iPhone. Всё на этой странице поступает из магазинов приложений, поэтому обновляется самостоятельно.

Easy-Post Desktop

Создавайте отправления, сравнивайте актуальные тарифы перевозчиков и печатайте этикетки на том компьютере, где идёт работа. Издания из магазинов обновляются сами и не требуют лицензионного ключа.

Загрузить в Mac App Store Получить в Microsoft Store

Для тех, кто предпочитает обойтись без магазина, версии для Windows и macOS доступны также как прямая загрузка. Этим сборкам нужен платный лицензионный ключ.

Easy-Post Mobile Companion

Отслеживание отправлений на телефоне после однократного сопряжения с настольным приложением. Установка бесплатна, а для сопряжения необходима платная рабочая лицензия Easy-Post Desktop.

Загрузить из App Store

Версия для Android проходит тестирование перед выпуском в Google Play. Подробнее о мобильном приложении.
