The Windows download is code-signed

From version 1.2.7 onwards, both executables carry a Microsoft-issued Public Trust signature in the name Spencer Fields, so Windows names the publisher instead of warning about one it does not recognise. Right-click the file, choose Properties, then Digital Signatures to see it.

A signature is new to this release, and SmartScreen builds its reputation from how often a signed application is downloaded and run. On a machine with Smart App Control switched on, a certificate this recent may still be held back. If that happens, the Microsoft Store build carries Microsoft’s own signature and is the smoother route.

To check the download yourself before running it, compare its checksum against the list below:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Getting started

  1. Install and open the application.
  2. Paste your licence key on the activation screen. It arrived by email when you bought — search for “Easy-Post Desktop licence key”. Store installs skip this step.
  3. Paste your EasyPost API key. Easy-Post Desktop sells no postage of its own; it drives your own EasyPost account. Sign up free at easypost.com. A test-mode key lets you try everything without buying real labels.

Changing computers later is expected and costs you nothing permanently — release the old machine from within the application, under Settings.

Requirements

  • Windows 10 version 1809 or later, 64-bit — or macOS on Apple silicon
  • An EasyPost account and API key
  • An internet connection to buy labels and to activate once
