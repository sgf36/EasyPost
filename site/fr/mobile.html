Mobile

Easy-Post Mobile Companion

Le suivi des expéditions sur le téléphone, en complément d'Easy-Post Desktop. Sur l'App Store pour iPhone, l'édition Android étant en test avant sa publication sur Google Play.

Obtenir l'application

iPhone — sur l'App Store, pour iOS 15 et versions ultérieures.

Télécharger sur l'App Store

Android — en test avant sa publication sur Google Play. Le téléchargement direct proposé ici auparavant a été retiré : une application installée de cette façon ne peut pas se mettre à jour elle-même, si bien que chaque nouvelle version laissait toutes les installations antérieures en arrière, sans aucun signalement qu'elles étaient dépassées. La version Play se mettra à jour normalement.

Une licence de production Easy-Post Desktop payante est requise pour l'association, sur l'une comme sur l'autre plateforme.

Associez une fois, puis suivez depuis n'importe où

Ouvrez Easy-Post Desktop, choisissez Associer l'application mobile, et scannez le code avec le téléphone. Dès lors, chaque expédition du compte EasyPost n'est qu'à un coup d'œil, où que la journée vous mène.

Ce qu'elle fait

  • Suivi en direct de chaque envoi, avec des icônes de statut claires et un code couleur par transporteur.
  • Trier et filtrer — par statut, par transporteur ou par numéro de suivi, et masquer les envois livrés d'un simple geste.
  • Une vue détaillée pour chaque colis, avec l'historique complet des scans et une carte approximative du trajet.
  • Notifications push lors des mises à jour de suivi, pour ne jamais manquer une livraison ou une anomalie.

Sécurisé par conception

L'appairage transmet un jeton à usage unique, jamais la clé de production. La clé est conservée chiffrée par le serveur, sous une forme qu'il ne peut pas lire lui-même, la clé de déchiffrement étant conservée dans le stockage sécurisé du téléphone. La clé n'est jamais affichée dans l'application. Le détail complet figure dans la politique de confidentialité mobile.

Configuration requise

Easy-Post Mobile Companion est une application compagnon d'Easy-Post Desktop et nécessite une licence de production payante pour cette application. Aucun compte d'expédition distinct n'est créé dans l'application.

Easy-Post est une application indépendante construite sur l'API EasyPost et n'est pas affiliée à EasyPost.
