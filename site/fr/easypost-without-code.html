Sans API · Sans tableau de bord · Votre propre compte

Utilisez EasyPost sans écrire une ligne de code

EasyPost est conçu pour les développeurs — mais vous n'avez pas besoin d'en être un pour l'utiliser. Easy-Post Desktop vous permet d'imprimer des étiquettes, de comparer les tarifs des transporteurs et de suivre les colis sur votre propre compte EasyPost depuis une application de bureau classique. Sans code, sans passer votre temps dans le tableau de bord web.

Gratuit à l'essai sur le Microsoft Store Consulter la FAQ

Le problème : EasyPost part du principe que vous savez coder

Les tarifs multi-transporteurs et les étiquettes d'EasyPost sont excellents, mais les deux seuls moyens d'y accéder sont une API pour développeurs et un tableau de bord web. Si vous voulez simplement acheter une étiquette, ou que votre équipe expédie toute la journée, développer contre l'API n'est pas réaliste et le tableau de bord n'est pas conçu pour le volume. De nombreux comptes EasyPost restent sous-exploités pour cette raison précise.

La solution : une application de bureau sur votre propre compte

Easy-Post Desktop se connecte à votre propre clé API EasyPost et la transforme en application pointer-cliquer :

  • Saisissez une adresse, choisissez un colis, et obtenez les tarifs de tous les transporteurs de votre compte, du moins cher au plus cher.
  • Achetez et imprimez une étiquette en quelques clics — PNG, PDF, ZPL ou EPL, au format adapté à votre imprimante.
  • Suivez vos colis, vérifiez les adresses, saisissez les données douanières et recherchez les codes tarifaires HTS.
  • Expédiez en masse un fichier CSV entier de commandes : importez, validez, tarifez et achetez.
  • Remboursements, assurances, enlèvements et réclamations — sans jamais ouvrir un terminal ou le tableau de bord.

L'affranchissement est facturé directement par EasyPost, l'application ne touche donc jamais à votre argent et n'applique aucune majoration.

Où puis-je obtenir une clé API EasyPost ?

Inscrivez-vous gratuitement sur easypost.com, puis copiez votre clé API depuis la page API Keys de votre compte. Collez-la dans Easy-Post Desktop au premier lancement. Utilisez une clé en mode test pour tout essayer sans frais réels de transporteur — l'application est gratuite en mode test, et un déblocage unique de 29,99 $ active les étiquettes de production (réelles) lorsque vous êtes prêt.

Vous préférez qu'un assistant IA s'en charge ?

L'application prend également en charge le Model Context Protocol (MCP), ce qui vous permet de connecter un agent IA — Claude, Cursor, VS Code — à vos données d'expédition pour comparer les tarifs et répondre à vos questions. Tout achat réel passe toujours par une étape d'approbation humaine dans l'application, afin que rien ne soit acheté sans vous.
