Windows affiche un avertissement bleu. C'est normal.

« Windows a protégé votre ordinateur » apparaît la première fois que vous lancez le téléchargement, car cette version n'est pas encore signée numériquement. Cliquez sur Plus d'informations, puis sur Exécuter quand même.

Ce n'est pas le signe d'un problème : SmartScreen affiche ce message pour toute application dont il ne reconnaît pas encore l'éditeur, et un certificat est en cours d'obtention. Si vous préférez vérifier le fichier vous-même avant de l'exécuter, comparez sa somme de contrôle à la liste ci-dessous :

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

La version du Microsoft Store est signée par Microsoft et n'affiche pas cet avertissement ; elle constitue donc la solution la plus simple sous Windows une fois que vous disposez d'une licence Store.

Pour commencer

  1. Installez et ouvrez l'application.
  2. Collez votre clé de licence sur l'écran d'activation. Elle vous a été envoyée par e-mail lors de l'achat — recherchez « Easy-Post Desktop licence key ». Les installations depuis le Store ignorent cette étape.
  3. Collez votre clé API EasyPost. Easy-Post Desktop ne vend pas d'affranchissement en propre ; l'application pilote votre propre compte EasyPost. Inscrivez-vous gratuitement sur easypost.com. Une clé en mode test vous permet de tout essayer sans acheter de véritables étiquettes.

Changer d'ordinateur par la suite est prévu et ne vous coûte rien de façon permanente — libérez l'ancienne machine depuis l'application, dans les Paramètres.

Configuration requise

  • Windows 10 version 1809 ou ultérieur, 64 bits — ou macOS sur Apple Silicon
  • Un compte EasyPost et une clé API
  • Une connexion internet pour acheter des étiquettes et pour activer une fois

Chaque version, avec ses notes et sommes de contrôle, est répertoriée sur GitHub. L'application est open source sous licence MIT ; le code source se trouve sur github.com/sgf36/EasyPost.
