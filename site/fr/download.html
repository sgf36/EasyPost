Le téléchargement Windows est signé numériquement

À partir de la version 1.2.7, les deux exécutables portent une signature Public Trust délivrée par Microsoft au nom de Spencer Fields, si bien que Windows indique le nom de l'éditeur au lieu d'émettre un avertissement au sujet d'un éditeur inconnu. Faites un clic droit sur le fichier, choisissez Propriétés, puis Signatures numériques pour la consulter.

La signature est arrivée avec la version 1.2.7, et SmartScreen construit sa réputation en fonction de la fréquence à laquelle une application signée est téléchargée et exécutée. Sur une machine où le Contrôle des applications intelligent est activé, un certificat aussi récent peut encore être bloqué. Dans ce cas, la version du Microsoft Store porte la signature propre de Microsoft et constitue la voie la plus simple.

Pour vérifier vous-même le téléchargement avant de l’exécuter, comparez sa somme de contrôle à la liste ci-dessous :

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Pour commencer

  1. Installez et ouvrez l'application.
  2. Collez votre clé de licence sur l'écran d'activation. Elle vous a été envoyée par e-mail lors de l'achat — recherchez « Easy-Post Desktop licence key ». Les installations depuis le Store ignorent cette étape.
  3. Collez votre clé API EasyPost. Easy-Post Desktop ne vend pas d'affranchissement en propre ; l'application pilote votre propre compte EasyPost. Inscrivez-vous gratuitement sur easypost.com. Une clé en mode test vous permet de tout essayer sans acheter de véritables étiquettes.

Changer d'ordinateur par la suite est prévu et ne vous coûte rien de façon permanente — libérez l'ancienne machine depuis l'application, dans les Paramètres.

Configuration requise

  • Windows 10 version 1809 ou ultérieur, 64 bits — ou macOS sur Apple Silicon
  • Un compte EasyPost et une clé API
  • Une connexion internet pour acheter des étiquettes et pour activer une fois
