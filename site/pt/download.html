A transferência para Windows está assinada digitalmente

A partir da versão 1.2.7, ambos os executáveis têm uma assinatura Public Trust emitida pela Microsoft em nome de Spencer Fields, pelo que o Windows indica o nome do editor em vez de avisar sobre um que não reconhece. Clique com o botão direito no ficheiro, escolha Propriedades e depois Assinaturas Digitais para o ver.

Uma assinatura é uma novidade nesta versão, e o SmartScreen constrói a sua reputação a partir da frequência com que uma aplicação assinada é descarregada e executada. Num computador com o Smart App Control ativado, um certificado tão recente ainda pode ser retido. Se isso acontecer, a versão da Microsoft Store tem a própria assinatura da Microsoft e é o caminho mais tranquilo.

Para verificar o download você mesmo antes de o executar, compare a soma de verificação com a lista abaixo:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Como começar

  1. Instale e abra a aplicação.
  2. Cole a sua chave de licença no ecrã de ativação. Foi enviada por email quando efetuou a compra — procure por “Easy-Post Desktop licence key”. As instalações através da Store dispensam este passo.
  3. Cole a sua chave de API da EasyPost. A Easy-Post Desktop não vende franquias postais próprias; utiliza a sua própria conta EasyPost. Registe-se gratuitamente em easypost.com. Uma chave em modo de teste permite-lhe experimentar tudo sem comprar etiquetas reais.

Mudar de computador mais tarde é normal e não tem custos permanentes — liberte o computador antigo a partir da aplicação, em Definições.

Requisitos

  • Windows 10 versão 1809 ou posterior, 64 bits — ou macOS em Apple Silicon
  • Uma conta EasyPost e uma chave API
  • Uma ligação à internet para comprar etiquetas e para ativar uma vez

Versões antigas e código-fonte

Todas as versões, com as respetivas notas e checksums, estão listadas no GitHub. A aplicação é de código aberto sob a licença MIT; o código-fonte está em github.com/sgf36/EasyPost.
