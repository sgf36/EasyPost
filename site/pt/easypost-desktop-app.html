Uma aplicação de ambiente de trabalho para o EasyPost

O EasyPost é uma API de envios. O Easy-Post Desktop é a aplicação nativa de ambiente de trabalho que assenta sobre ela — para que possa comparar tarifas, comprar e imprimir etiquetas e seguir encomendas na sua própria conta EasyPost sem escrever código nem viver dentro de um painel no navegador.

Experimente gratuitamente na Microsoft Store Ver preços

Porquê uma aplicação de ambiente de trabalho para o EasyPost?

O EasyPost oferece um excelente serviço de envios multi-transportadora, mas, tal como vem por definição, ou escreve código contra a API ou trabalha no painel Web. Se é um comerciante, alguém das operações ou uma equipa de armazém, nenhuma dessas opções é o que quer para imprimir etiquetas o dia todo. O Easy-Post Desktop é uma verdadeira aplicação nativa (Windows e macOS) que se liga à sua própria conta EasyPost e chave API e disponibiliza todo o fluxo de trabalho numa interface rápida e focada.

É uma interface, não um revendedor: os portes são faturados diretamente pela EasyPost, e a aplicação nunca acrescenta margem nem toca no seu dinheiro.

O que a aplicação faz

  • Comparação de tarifas — compare tarifas em tempo real entre USPS, FedEx, UPS e todas as transportadoras da sua conta, começando pela mais barata.
  • Etiquetas — compre e imprima em PNG, PDF, ZPL ou EPL, exatamente no tamanho que a sua impressora espera.
  • Seguimento — monitorize encomendas com verificação automática ou atualizações opcionais em tempo real.
  • Livro de endereços e verificação — campos adaptados a cada país, cobrindo 197 países.
  • Pesquisa de alfândega e HTS — capture dados completos de alfândega e pesquise códigos tarifários dos EUA em tempo real.
  • Reembolsos, seguro, recolhas, reclamações e lote CSV — todo o ciclo de vida do envio num só lugar.
  • Acesso a agentes de IA (MCP) — ligue um assistente como o Claude ou o Cursor aos seus dados de envio para comparar tarifas, com todas as compras aprovadas por si na aplicação.

Gratuito para experimentar, preços honestos

A aplicação é gratuita para instalar e funciona totalmente no modo de teste do EasyPost, para que possa avaliar todo o seu fluxo de trabalho na sua conta antes de pagar seja o que for. Um desbloqueio único de 29,99 $ ativa etiquetas de produção no seu computador — sem subscrição, sem contagem decrescente. As equipas que precisem de vários computadores podem licenciar por posto neste site.

Privado e aberto

A sua chave API é guardada no Windows Credential Manager e é enviada apenas para a API do EasyPost. Os dados de envio permanecem na sua máquina — sem análises, sem telemetria. A aplicação é de código aberto sob a licença MIT, pelo que nada na forma como interage com a sua conta fica oculto.
