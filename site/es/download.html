La descarga de Windows está firmada digitalmente

A partir de la versión 1.2.7, ambos ejecutables llevan una firma de confianza pública emitida por Microsoft a nombre de Spencer Fields, por lo que Windows muestra el nombre del editor en lugar de advertir sobre uno que no reconoce. Haga clic con el botón derecho en el archivo, elija Propiedades y luego Firmas digitales para verla.

La firma llegó en la versión 1.2.7, y SmartScreen construye su reputación según la frecuencia con la que se descarga y ejecuta una aplicación firmada. En un equipo con Smart App Control activado, un certificado tan reciente puede seguir siendo bloqueado. Si eso ocurre, la versión de Microsoft Store lleva la propia firma de Microsoft y es la vía más sencilla.

Para comprobar usted mismo la descarga antes de ejecutarla, compare su suma de comprobación con la lista siguiente:

powershell -Command "Get-FileHash .\EasyPostDesktop-Windows-x64.zip -Algorithm SHA256"

Primeros pasos

  1. Instale y abra la aplicación.
  2. Pegue su clave de licencia en la pantalla de activación. Le llegó por correo electrónico al comprar; busque «Easy-Post Desktop licence key». Las instalaciones desde la Store omiten este paso.
  3. Pegue su clave de API de EasyPost. Easy-Post Desktop no vende franqueo propio; funciona conectándose a su propia cuenta de EasyPost. Regístrese gratis en easypost.com. Una clave en modo de prueba le permite probarlo todo sin comprar etiquetas reales.

Cambiar de ordenador más adelante es algo previsto y no tiene coste permanente: libere el equipo anterior desde dentro de la aplicación, en Configuración.

Requisitos

  • Windows 10 versión 1809 o posterior, de 64 bits, o macOS en Apple silicon
  • Una cuenta de EasyPost y una clave de API
  • Una conexión a internet para comprar etiquetas y para activar una vez
