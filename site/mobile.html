Mobile

Easy-Post Mobile Companion

Shipment tracking on the phone, as a companion to Easy-Post Desktop. Available now for Android as a direct download, with the iPhone edition arriving on the App Store.

Get the app

Android — download the signed app directly and install it. Its Google Play listing is still being prepared, so for now it is offered as a direct download; it installs and pairs exactly the way the store version will.

Download for Android (APK)

On the phone, open the downloaded file and allow installation from this source if prompted. Requires Android 7.0 or later. A paid Easy-Post Desktop production licence is required to pair.

iPhone — arriving on the App Store. This page will link it as soon as it is available.

Pair once, then track anywhere

Open Easy-Post Desktop, choose Pair mobile app, and scan the code with the phone. From then on, every shipment on the EasyPost account is a glance away, wherever the day goes.

What it does

  • Live tracking of every shipment, with clear status icons and carrier colour-coding.
  • Sort and filter — by status, by carrier or by tracking code, and hide delivered shipments in a tap.
  • A detailed view for each parcel, with the full scan history and an approximate journey map.
  • Push notifications on tracking updates, so a delivery or an exception is never missed.

Secure by design

Pairing carries a one-time token, never the production key. The key is held encrypted by the backend in a form it cannot read on its own, with the decryption key kept in the phone's secure store. The key is never shown in the app. Full detail is in the mobile privacy policy.

Requirements

Easy-Post Mobile Companion is a companion to Easy-Post Desktop and requires a paid production licence for that application. A separate shipping account is not created in the app.

Easy-Post is an independent application built on the EasyPost API and is not affiliated with EasyPost.
